# RPG게임 프로젝트
- 리슨 서버를 이용한 멀티플레이 RPG 게임 제작
- Unreal Engine 5 사용
## 구현 목록
1. **아이템 시스템**
    - 데이터 테이블과 구조체를 이용하여 아이템 데이터를 관리하고, 아이템 인스턴스에 데이터를 동적으로 적용
    - 장착 부위는 열거형(Enum) 기반으로 관리하여 슬롯 구조를 유연하게 확장 가능하도록 설계
    - 아이템 데이터와 실제 동작 로직을 분리하여 유지보수성과 콘텐츠 추가 효율 향상
2. **스킬 시스템**
    - 스킬 타입 열거형과 유형별 구조체를 정의하여 투사체, 범위형 등 다양한 스킬 데이터를 데이터테이블로 관리
    - 스킬 유형마다 스킬 베이스 클래스를 상속한 개별 클래스를 구현하여 기능 확장이 가능하도록 설계
    - 새로운 스킬 추가 시 데이터와 클래스만 추가하면 동작할 수 있도록 구조화
3. **아이템 및 스킬 장착 UI**
    - 메인 UI 위젯이 하위 위젯을 관리하는 구조로 UI 계층 설계
    - HUD 클래스에서 UI 활성 상태를 통합 관리하여 UI 흐름 제어
    - 데이터테이블을 순회하며 동적으로 하위 위젯을 생성하고, 각 위젯에 아이템 및 스킬 정보를 저장
4. **UI와 캐릭터 데이터 연동**
    - 이벤트 디스패처를 이용하여 UI와 캐릭터 데이터를 연결하고 장착 상태 변경을 실시간 반영
    - 아이템 장착 시 구조체 연산자 오버라이딩을 활용하여 플레이어 스탯을 계산 및 적용
    - 데이터 변경 시 UI와 캐릭터 상태가 동시에 갱신되도록 이벤트 기반 구조로 구현
5. **장비 기반 플레이어 외형 변경**
    - 베이스 스켈레탈 메쉬 하위에 장비용 메쉬 컴포넌트를 추가하여 부위별 장비 구현
    - 자식 메쉬가 부모 메쉬의 애니메이션을 복사하도록 설정하여 장비 장착 시 자연스럽게 동작하도록 구현
    - 장비 변경에 따라 플레이어 외형이 실시간으로 반영되도록 시스템 구성
