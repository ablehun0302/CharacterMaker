## 주요 기능 및 문제 해결
| 주요 기술 | 사용처 |
| --- | --- |
| Firebase Auth REST API | 플레이어 회원가입, 로그인 |
| 리슨 서버 기반 네트워크 동기화 | 플레이어 간 캐릭터 위치, 아이템 장착 상태, 사망 연출 등<br>멀티플레이 동기화 |
| Primary Data Asset | 스킬 시스템 |
| Data Table | 아이템 시스템 |
| Actor Component | 플레이어, 몬스터 체력, 공격력 등 스탯 시스템 |
| Behavior Tree | 몬스터 AI |

### 문제 해결
1. 여러 개의 Primary Data Asset기반 스킬 에셋을 비동기 로딩하는 과정에서 로딩 완료 시점이 제각각 달라져 스킬창 UI의 슬롯 순서가 꼬이는 현상
    - 로딩이 완료된 스킬 오브젝트의 고유 ID(FPrimaryAssetId)로 기존 스킬 목록 안의 인덱스 위치를 역추적하여<br>정확한 슬롯 위치에 동기화되도록 로직을 개선.
2. 닉네임 저장/불러오기 함수가 각각 별도의 콜백을 갖고 있었으나, 콜백 내부의 응답 파싱 로직(JSON → 닉네임 추출)이 완전히 동일한 코드 중복 발생
    - 파싱 로직은 공통 함수로 분리하고, 파싱 이후 실행할 동작만 TFunction(람다)으로 주입받도록 구조 변경

### 세부 구현 항목
1. **Firebase를 활용한 회원가입, 로그인 시스템**<br><br>
<img width="500" alt="로그인 시스템 시퀀스 다이어그램" src="https://github.com/user-attachments/assets/27c8ed08-8a85-4883-8d40-338f54675a4f" /> <br><br>
    - 게임 내에서 로그인하는 빈도가 낮고 실시간 동기화가 필요하지 않기에 웹서버 방식을 선택.
    - 로그인 정보는 AuthSubsystem에 저장되어 레벨 전환과 무관하게 인증 정보를 유지할 수 있음.
2. **캐릭터, 몬스터 스탯**
    - 캐릭터와 몬스터가 공통으로 사용하는 스탯 컴포넌트를 구현하여 체력, 공격력 등 데이터 관리.
    스탯 로직을 Actor Component로 분리하여 여러 액터에서 재사용할 수 있도록 함.
3. **아이템 착용/해제**<br>
<img width="500" alt="RepNotify아이템갱신_시퀀스다이어그램" src="https://github.com/user-attachments/assets/5ec24ef3-de8a-41e7-8c0d-4b7bca30a08a" /> <br>
    - Culling Distance로 인해 액터가 다시 생성되어도 장착 상태가 복원되도록 하기 위함.
    - Player State를 이용하여 리스폰 이후에도 사망 전 장착한 장비를 복원할 수 있도록 함.
    Multicast RPC로 사망 연출을 호출하면 복제된 체력과 사망 처리 타이밍이 어긋날 수 있기에 이런 오류를 해결하기 위함.
4. **UI와 캐릭터 데이터 연동**
    - UI의 상호작용은 Player Controller를 통해 Server RPC를 호출하고 캐릭터 로직을 수행.
    클라이언트가 데이터를 직접 변경하지 않도록 분리하기 위함.
5. **스킬 착용/ 해제, 사용**<br>
<img width="500" alt="스킬_클래스다이어그램" src="https://github.com/user-attachments/assets/b8e47680-1c89-42e5-a484-10bf3c950ccd" /> <br>
    - 스킬을 데이터 중심으로 관리하여 불필요한 액터 생성 비용을 줄이고, 새로운 스킬 추가 시 데이터 에셋만 제작하면 됨.
6. **Firebase에 닉네임 저장**
    - Firebase 컬렉션은 user_info, 문서는 플레이어의 UID로 설정하고 nickname을 저장할 수 있음.
    - 닉네임 저장을 위해 로그인 후 IdTocken이 필요

### 개발 진행 상황
    - 문제점: 클라이언트가 닉네임을 바꾸는 속도보다 서버가 닉네임 설정하는 속도가 더 빨라서 클라이언트가 처음 접속 시 리슨 서버 호스트가 클라이언트의 닉네임을 볼 수 없음. (해결)
